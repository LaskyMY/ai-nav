API 文档

AI Nav 后端API接口说明 · 基础URL: http://localhost:8765

天气

GET/api/weather?lat=&lon=
Open-Meteo 天气数据，返回当前温度/湿度/风速/预报

新闻

GET/api/news
多源新闻聚合 (NPR RSS + 中文热榜)
GET/api/news-cn
AI翻译+优先级排序的中文新闻
GET/api/news-summary
DeepSeek AI 生成的新闻简报

数据库

GET/api/db/stats
各表数据量统计
GET/api/db/news?limit=50
分页获取新闻
GET/api/db/search?q=关键词
全文搜索新闻
GET/api/db/summaries?type=news-summary
AI摘要历史
GET/api/db/pages
页面访问统计

金融

GET/api/financial/briefs?days=10
金融早晚简报
GET/api/financial/latest
最新金融简报

站点

GET/api/site/config
站点配置
GET/api/site/pages
页面元数据列表
GET/api/site/nav
导航结构
GET/api/site/changelog
更新日志
GET/api/site/sitemap-db
数据库驱动的网站大纲
GET/api/site/git-log
Git 提交记录

课程

GET/api/course/list
全部课程列表
GET/api/course/:slug
单课详情

论文

GET/api/papers?q=关键词
arXiv 论文检索
POST/api/summary
DeepSeek AI 文本总结
GET/api/geocode?lat=&lon=
经纬度→城市名
GET/api/usage
API 用量统计
