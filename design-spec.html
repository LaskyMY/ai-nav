AI Nav 页面设计规范 v1.0

本文档定义 AI Nav 网站所有页面的视觉设计、交互行为和组件规范。所有页面必须严格遵循本规范。本规范基于 index.html（主页）和 knowledge.html（百科页）提炼而成，是网站的设计真理来源。

设计哲学：液态玻璃（Glass Morphism）+ 暗色深空背景 + 流动渐变 + 微交互反馈。核心感觉：高级、冷静、科技、轻盈。不是扁平设计，而是有深度、有层次、有呼吸感的界面。

一、颜色系统（Color System）

1.1 CSS 变量定义

所有颜色必须通过 CSS 变量引用，禁止硬编码色值（背景和基础文本除外）。

:root {
  --bg:    #0a0a0f;   /* 页面背景 — 不是纯黑，带微蓝底调 */
  --a1:    #6366f1;   /* 主色 — 靛蓝紫 */
  --cyan:  #06B6D4;   /* 强调色 — 青色 */
  --pink:  #ec4899;   /* 点缀色 — 粉红 */
  --amber: #F59E0B;   /* 警告色 — 琥珀 */
  --green: #10B981;   /* 成功色 — 翠绿 */
  --red:   #EF4444;   /* 危险色 — 红色 */

  --tx:    rgba(255,255,255,.92);  /* 主文字 */
  --tx2:   rgba(255,255,255,.55);  /* 次要文字 */
  --tx3:   rgba(255,255,255,.35);  /* 辅助文字 */
  --tx4:   rgba(255,255,255,.18);  /* 禁用文字 */

  --card-bg:    rgba(255,255,255,.06);  /* 卡片背景 */
  --card-border:rgba(255,255,255,.08);  /* 卡片边框 */

  --r: 16px;  /* 标准圆角 */
  --ease: cubic-bezier(.22,1,.36,1);  /* 弹性缓动 */
}

四、背景系统（Background System）

4.1 暗色基底

body { background: #0a0a0f; }

不是纯黑(#000)，而是带极微弱蓝底调的深空色。这个颜色在不同屏幕上看起来像"有深度的黑"而不是"关屏的黑"。

4.2 浮动光球（Background Orbs）必须

所有页面body内第一个元素必须是光球容器。2-3个巨大模糊光球，提供环境光感。每个光球独立动画，参数错开。

<div class="bg">
  <div class="bg__orb"></div>
  <div class="bg__orb"></div>
  <div class="bg__orb"></div>  <!-- 可选第三个 -->
</div>

.bg { position: fixed; inset: 0; overflow: hidden; pointer-events: none; z-index: 0; }
.bg__orb {
  position: absolute; border-radius: 50%; filter: blur(120px);
  opacity: 0.4-0.5; will-change: transform;
}
.bg__orb:nth-child(1) {
  width: 500px; height: 500px;
  background: radial-gradient(circle, var(--a1) 0%, transparent 70%);
  top: -15%; left: -10%;
  animation: floatOrb 20s ease-in-out infinite;
}
.bg__orb:nth-child(2) {
  width: 400px; height: 400px;
  background: radial-gradient(circle, var(--pink) 0%, transparent 70%);
  bottom: -10%; right: -8%;
  animation: floatOrb 24s ease-in-out infinite reverse;
}

@keyframes floatOrb {
  0%,100% { transform: translate(0,0) scale(1); }
  25%    { transform: translate(80px,-60px) scale(1.15); }
  50%    { transform: translate(-40px,40px) scale(0.9); }
  75%    { transform: translate(-60px,-30px) scale(1.1); }
}

4.3 鼠标跟随光晕（Glow Spot）必须

所有桌面端页面必须有。移动端（touch设备）自动禁用。光晕跟随鼠标移动，有0.05系数的平滑lerp过渡。

<div class="glow-spot" id="glowSpot"></div>

.glow-spot {
  position: fixed; inset: 0; pointer-events: none; z-index: 0;
  opacity: 1; transition: background .3s ease;
}

// JS — 必须在每个页面的 <script> 中包含
(function(){
  var g = document.getElementById('glowSpot');
  if (!g || 'ontouchstart' in window) return;  // 移动端不启用
  var x = innerWidth/2, y = innerHeight/2, tx = x, ty = y;
  document.addEventListener('mousemove', function(e) {
    tx = e.clientX; ty = e.clientY;
  });
  function anim() {
    x += (tx - x) * 0.05;  // lerp平滑
    y += (ty - y) * 0.05;
    g.style.background = 'radial-gradient(circle 420px at '+
      x.toFixed(0)+'px '+y.toFixed(0)+'px, '+
      'rgba(99,102,241,.06) 0%, rgba(236,72,153,.035) 18%, '+
      'rgba(6,182,212,.02) 42%, transparent 70%)';
    requestAnimationFrame(anim);
  }
  anim();
})();

六、动画系统（Animation System）

6.1 动画原则

  • 缓动优先：所有动画使用 cubic-bezier(.22,1,.36,1) —— 弹性缓出，自然不生硬
  • 时长控制：微交互 0.15-0.25s，页面切换 0.3-0.5s，背景动画 20-24s
  • 性能优先：只动画 transform 和 opacity（GPU加速），不动画 width/height/left/top
  • 减少动画：尊重 prefers-reduced-motion 媒体查询

6.2 标准动画清单

动画时长缓动触发
标题渐变动画5sease-in-out自动循环 (tFlow)
光球浮动20-24sease-in-out自动循环 (floatOrb)
卡片fadeUp入场.5svar(--ease)页面加载 (fadeUp)
卡片悬停抬高.35svar(--ease):hover
按钮按下缩放.12sease:active (scale .96)
光晕跟随鼠标连续lerp 0.05mousemove
脉冲指示器1sease自动循环 (pulse)

6.3 fadeUp 入场动画（卡片列表必须）

  from { opacity: 0; transform: translateY(20px) scale(.96); }
  to   { opacity: 1; transform: translateY(0) scale(1); }

/* 级联延迟 — 每张卡片错开0.03s */

.card:nth-child(2) { animation-delay: .06s; }

十一、交互规范

11.1 按钮反馈

所有可点击元素必须有三级反馈：

  1. 默认态：半透明背景 + 微边框
  2. 悬停态：边框变亮 + 背景加深 + 微抬高(2px)
  3. 按下态：scale(.96) + 无transition延迟

11.2 链接规范

  • 页面内导航链接：使用标准 .btn 样式
  • 文字内链接：颜色 var(--cyan)，hover下划线
  • 卡片链接：整张卡片可点击，cursor:pointer
  • 外部链接：target="_blank" + rel="noopener"

11.3 加载状态

  • 数据加载中：显示 "加载中..." 文本+脉冲动画
  • 加载失败：显示 "⚠️ 加载失败，请检查网络"
  • 空数据：显示 "📭 暂无数据" + 说明文字

11.4 表单规范

input, textarea, select {
  background: rgba(255,255,255,.04);
  border: 1px solid rgba(255,255,255,.1);
  border-radius: 6px; padding: 8px 10px;

input:focus {

十三、性能规范

  • CSS优先：动画使用CSS transform+opacity（GPU合成），避免JS动画
  • will-change：仅在需要动画的元素上使用（光球、光晕），不要全局加
  • 请求动画帧：连续动画使用 requestAnimationFrame，不要用 setInterval
  • 字体加载：使用系统字体栈，不加载Google Fonts（国内被墙）
  • 图片：使用SVG图标，不使用位图icon
