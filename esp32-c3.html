📶 WiFi 配网说明 (WiFiManager)
ESP32 上电后会自动尝试连接已保存的WiFi。 如果连接失败，会自动进入 配网模式： 1. 打开手机 WiFi设置 2. 连接热点 "AI-NAV-C3-Setup" 3. 手机会自动弹出配网页面 (如未弹出，浏览器打开 192.168.4.1) 4. 点击 "Configure WiFi" 5. 选择你的WiFi，输入密码，保存 6. ESP32 自动重启并连接 ✅ 连接成功后状态LED 常亮 ❌ 配网中LED会 闪烁5次 提示 配网成功后，下方 HTTP API 控制 区域自动出现。
