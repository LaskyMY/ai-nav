ESP32 开发板入门

从零搭建开发环境 · 烧录第一个程序

一、认识 ESP32

ESP32 是乐鑫科技(Espressif)推出的双核 Wi-Fi + 蓝牙 MCU，Arduino IDE 可直接编程。

型号特点价格
ESP32-WROOM-32经典款，引脚最多，双核240MHz~¥15
ESP32-C3 Super MiniRISC-V单核160MHz，小巧便宜~¥8
ESP32-S3双核+USB OTG+AI加速，性能最强~¥25
本教程以 ESP32-C3 Super Mini 为例（就是你手上的那块），其他型号步骤通用。

二、安装 Arduino IDE

1
去 arduino.cc/en/software 下载对应系统版本（Windows/Mac/Linux）
2
安装后打开 Arduino IDE
3
Mac注意：首次打开如果提示"无法验证开发者"，去 系统偏好设置→安全性与隐私→仍然允许

三、安装 ESP32 开发板支持包

1
Arduino IDE → 设置/Preferences
2
在"附加开发板管理器网址"中添加：
https://espressif.github.io/arduino-esp32/package_esp32_index.json
3
工具 → 开发板 → 开发板管理器
4
搜索 "esp32" → 安装 "esp32 by Espressif Systems"（版本选最新）
5
等待下载完成（约500MB，需要科学上网或耐心等待）
如果下载慢，可以用国内镜像：将 espressif.github.io 换成 espressif.cdn.microsoc.cn

四、安装 USB 驱动

芯片驱动
CH340/CH341（最常见）搜索下载 CH340 驱动，Mac/Linux通常免驱
CP2102Silicon Labs CP210x 驱动
CH9102WCH CH9102 驱动
1
ESP32-C3通过USB线连接电脑
2
Mac: 打开 终端，输入 ls /dev/cu.*，看到 /dev/cu.usbserial-XXXX 说明驱动OK
3
Windows: 设备管理器 → 端口(COM和LPT) → 看到 USB-SERIAL CH340 (COMx)

五、配置开发板参数

Arduino IDE 菜单栏选择：

开发板ESP32C3 Dev Module
USB CDC On BootEnable（启用串口输出）
CPU Frequency160MHz
Flash Size4MB
Partition SchemeHuge App (3MB No OTA/1MB SPIFFS)
Upload Speed921600
分区方案为什么选Huge App？
WiFi+BLE库很大，默认分区放不下会报错"sketch too big"。Huge App给程序3MB空间，足够用。

六、烧录第一个程序：LED 闪烁

1
复制以下代码到 Arduino IDE：
void setup() {
  pinMode(8, OUTPUT);  // GPIO8 = 板载LED
}
void loop() {
  digitalWrite(8, HIGH);
  delay(500);
  digitalWrite(8, LOW);
  delay(500);
}
2
点击 → (上传) 按钮，等待编译+烧录
3
看到 "Leaving... Hard resetting via RTS pin..." 表示成功
4
板载LED开始每秒闪烁一次 ✅

七、常见问题

问题解决
上传失败 "Connecting..."按住BOOT键再点上传，出现"Connecting"后松开
找不到串口检查USB线是否数据线（不是充电线），重装驱动
编译报错 "sketch too big"分区方案选 Huge App
上传后没反应按一下 RST(EN) 键复位，或拔插USB
Mac 弹窗"无法验证"系统偏好→安全性与隐私→仍然允许
串口监视器乱码波特率设置为 115200

八、ESP32-C3 Super Mini 引脚图

         ┌──────────────────────┐
    USB──│ 5V              GND  │──GND
         │ GND             3.3V │──3.3V
    TX──│ GPIO21          GPIO20│──RX
    RX──│ GPIO20          GPIO21│──TX
         │ GPIO10          GPIO9│
         │ GPIO8           GPIO7│──蜂鸣器
    LED──│ GPIO8(板载)     GPIO6│──RGB-B
         │ GPIO5           GPIO4│──RGB-G
         │ GPIO3(按键3)    GPIO2│──RGB-R
         │ GPIO1(按键1)    GPIO0│──按键0(BOOT)
         │ 3.3V           GND  │
         │ RST(EN)        5V   │
         └──────────────────────┘
GPIO0-GPIO3 可做按键输入（内置上拉）
GPIO4-6 可做 PWM 输出(RGB LED)
GPIO7-10 通用 IO
GPIO20-21 默认 UART(RX/TX)
