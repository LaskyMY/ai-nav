二、表笔怎么插

插孔颜色用途
COM黑表笔公共地（永远插这里）

下次测电压如果红表笔还在10A孔 = 短路 = 烧表烧保险！

三、最常用：蜂鸣档（通断测试）

这是日常使用最多的档位，用来检查导线是否连通、焊点是否虚焊、PCB走线是否断路。

1
红表笔插 VΩmA，黑表笔插 COM
2
旋钮转到 蜂鸣档 )))（通常和电阻档在一起）
3
两个表笔碰一下 → 听到 "嘀——" 声 + 屏幕显示接近0Ω = 万用表正常
4
测导线两端 → 响 = 连通 / 不响 = 断路
5
测焊点两端 → 响 = 焊接OK / 不响 = 虚焊或断路

四、测电压（DCV 直流）

测电池、电源、开发板供电。

1
旋钮转到 V⎓ (DCV)，选合适量程（不知道就选最大 20V/200V）
2
红表笔接 正极(+)，黑表笔接 负极(-)
3
读数 = 电压值

红黑表笔接反了？没关系，屏幕显示负号(-)而已。数字表不怕反接。

五、测交流电压（ACV）⚠️ 危险

测220V市电有触电风险！新手建议只在低压直流电路中使用。

安全守则：
• 表笔绝缘层不能破损
• 手不要碰到表笔金属部分
• 旋钮必须打到 V~ 750V 档
• 不确定的情况下不要测

1

2

在线路中测电阻不准（受其他元件影响）。准确测量需要拆下来单独测。

七、测电流（DCA）

电流测量和电压不一样！表笔要串联在电路中。

⚠️ 最常见的烧表操作：
旋钮在电流档，表笔却并联去测电压 = 短路！
电流档内阻极小（接近0Ω），直接测电源两端 = 电源短路 = 烧保险甚至烧表。

所以：测完电流立刻把旋钮转回电压档！
1
小电流(<200mA): 红表笔插 VΩmA，旋钮选 200mA⎓
2
大电流(>200mA): 红表笔插 10A，旋钮选 10A⎓
3
断开电路 → 万用表串联接入断口 → 通电读数

八、测二极管 / LED

判断LED好坏、极性、颜色。

1
旋钮转到 二极管档 (→+)
2
红笔接LED长脚(+)，黑笔接短脚(-) → LED微亮，显示1.5~2.5V = 正常
3
反过来接 → 显示 OL (Open Loop) = 正常（二极管单向导通）
4
如果两个方向都通 或 两个方向都不通 = LED坏了
