怎么跟AI说话

"帮我写个网页" vs "帮我写一个深色待办列表，能添加删除，存在浏览器本地"——差距就是六个字：具体、具体、具体
得分: 0
🎯 好Prompt = 角色 + 任务 + 标准 + 约束。点击掉落的好Prompt元素得分，避开模糊的！

核心要点

  • 四要素：角色(你是谁) + 任务(做什么) + 标准(怎么算好) + 约束(不能做什么)
  • "帮我写个网页"=AI猜100件事。详细版=AI一次做对
  • 改bug时：贴完整报错+贴代码+说"我已经试过XX了"
  • 好Prompt让AI一次就做对，省下反复修改的时间

动手试试

  • 用四要素模板写一个Prompt发给AI
  • 同一个需求，写模糊版和详细版，对比结果
  • 下次AI结果不满意，直接说"不对，我要的是XX"
