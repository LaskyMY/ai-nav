编程语言大观园

小K 听说过的编程语言一只手就能数过来——C++、Python、Java。 但网上随便一刷，什么 JavaScript、TypeScript、C#、Rust、Go…… 怎么会有这么多种？哪个才是我该学的？

📚 课程目录
SCENE · 第四天午休

小K："G哥，你写 C++。那隔壁组前端写 React 用的是什么？TypeScript？这是 C++ 的弟弟吗？"

G 哥（放下咖啡杯）： "好问题。你先记住一句话—— 编程语言是人类写给自己的工具，每一种都是为特定场景设计的。 就像你不会用菜刀去拧螺丝，也不会用扳手去切菜。"

为什么要懂这个

你不了解语言之间的关系，就永远不知道"自己该学什么"。

很多新人上来就问"学哪个语言好找活？"，但这个问题本身就不对—— 因为不同语言通向完全不同的职业方向。你今天要做的，不是学一门具体语言， 而是在脑子里画一张"语言地图"，知道每种语言长什么样、在什么场景下用、彼此之间是什么关系。

为什么会有这么多种语言？

回到 Day 0 那个核心公式：代码 = 人类可读的东西 → 翻译 → 机器指令。

每一种"翻译方式"和"人怎么描述问题"的组合，就是一门新的编程语言。 1972 年诞生的 C 语言，是为了写 Unix 操作系统。1995 年的 Java，是为了"写一次，到处跑"。 2009 年的 Go，是为了解决 Google 后院几万台服务器的并发问题。

每种语言都诞生于一个具体的痛点上。 理解了这一点，你就不会觉得"语言太多"了——就像你不会觉得"螺丝刀种类太多"一样， 因为十字、一字、六角，各有各的用场。

七大主流语言速览

下面不用深入学语法，只需要看懂每种语言"长什么样"和"用在什么地方"。

1. C++ —— 性能猛兽，UE 的心脏

UE 引擎本身就是 C++ 写的。C++ 的特点是极其快、极其精细—— 你能控制内存的每一个字节，但这也意味着你一不小心就会把内存写坏（"野指针"、"内存泄漏"是 C++ 新人的噩梦）。 游戏引擎、操作系统、数据库、高频交易——凡是需要"每一毫秒都要省"的地方，基本都是 C++。

// C++ — 静态类型，编译型，手动内存管理
#include <iostream>
int main() {
    std::cout << "Hello UE!" << std::endl;
    return 0;
}

2. Python —— 读起来像英语，AI 时代的通用语

Python 的设计哲学是"代码应该像伪代码一样好读"。它不用编译，写完就直接跑。 UE 里用来做编辑器脚本、批量处理资产。AI/机器学习领域几乎默认用 Python。 缺点是慢——同样一个循环，Python 可能比 C++ 慢几十倍。

# Python — 动态类型，解释型，自动内存管理
print("Hello from Python!")

3. JavaScript —— 网页的语言，浏览器里唯一能跑的

全世界每一台电脑的浏览器都内置了 JavaScript 引擎。你打开的任何一个网页，上面的按钮、动画、 表单验证，大概率都是 JS 写的。JS 曾经只是一个"网页小脚本"，但现在它跑到了服务器端（Node.js）、 桌面端（Electron）、甚至移动端（React Native）。

// JavaScript — 动态类型，解释型/JIT
console.log("Hello from the browser!");

4. TypeScript —— JS 穿了盔甲

JS 的变量没有"类型"——一个变量可以先是数字，再变成字符串，再变成对象。 这在大型项目里是灾难：你改了一个地方，不知道哪里会炸。 TypeScript 给 JS 加上了类型系统——写的时候稍微麻烦一点，但编译的时候就能帮你抓出大部分低级错误。 我们的 FloatThings 待办事项就是用 TypeScript 写的。

// TypeScript — JS + 静态类型检查
function greet(name: string): string {
    return `Hello, ${name}!`;
}

5. Java —— 企业级的老大哥

Java 的核心卖点是"写一次，到处跑"。你的 Java 代码编译成字节码后， 可以在任何装了 JVM 的机器上跑——Windows、Mac、Linux、甚至冰箱里的嵌入式系统。 银行系统、安卓 App、企业后台，大量使用 Java。但对 UE 开发来说基本用不到。

6. C# —— 微软的亲儿子，Unity 的心脏

C# 可以理解为"Java 的表弟，微软的亲儿子"。语法和 Java 很像，但更现代化。 如果你用 Unity 做游戏而不是 UE，那你写的就是 C#。UE 开发基本用不到，但值得认识它。

7. Rust —— 新来的安全专家

Rust 是 Mozilla 在 2015 年推出的语言，设计目标是"C++ 的性能，但没有 C++ 的内存陷阱"。 它的编译器极其严格——任何可能的内存错误都会在编译期被拦下，根本不给跑到线上的机会。 Windows 内核、Linux 内核、Firefox 浏览器都在逐步引入 Rust。 对新人来说学习曲线很陡，但它代表了编程语言未来的方向。

两大阵营：编译型 vs 解释型

🔨 编译型（C++, Rust, Go） 代码 → 编译器翻译 → 机器码 .exe
跑起来快，但每次改完都要等编译。
UE 里改一行可能要编译几十秒到几分钟。
⚡ 解释型（Python, JavaScript） 代码 → 直接交给解释器跑
改了就能跑，不需要编译等待。
但跑起来比编译型慢很多。
🏷️ 静态类型（C++, Java, TS, Rust, C#） 变量的类型在写代码时就定死。
int x = 5; → x 永远是整数。
能提前抓很多错，但写起来啰嗦。
🏷️ 动态类型（Python, JS） 变量的类型在运行时才确定。
x = 5 然后 x = "hello" 完全合法。
写起来快，但容易埋坑。
🔑 UE 开发者的语言组合

对 UE 工具开发来说，你真正需要的是：C++（引擎层，写插件核心逻辑）+ Python（编辑器脚本，批量操作）+ 蓝图（不是编程语言但能干活）。TypeScript 如果你有兴趣做我们的实践课，也会接触到。

你该学哪门？取决于你想做什么

如果你现在什么都不会，从 Python 入门最容易。
如果你想做 UE 工具开发，C++ 是绕不开的主线。
两者不矛盾——先 Python 感受"编程是怎么回事"，再啃 C++。
