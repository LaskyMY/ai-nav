三件套就够了

不需要装一百个软件。核心就三个：一个写代码的地方（VS Code，免费）、一个打命令的地方（终端，电脑自带）、一个存代码的地方（Git，五分钟学会）。这三个就像笔、纸和文件夹——你不需要先学一年书法再开始写字。装好一次就不用再管。
🖱 翻开卡片找配对——记住三件套

核心要点

  • VS Code：下载→安装→打开文件夹→开始写。就这么简单
  • 终端：黑窗口，你打字，它执行。不可怕
  • Git：存档→修改→不满意就回档。游戏里的存档读档
  • 先装VS Code和Git，终端边用边学
  • 每个工具只需要学会一个操作：VS Code打开文件，终端ls看目录，Git commit存档

动手试试

  • 下载安装VS Code
  • 打开终端，输入 ls（Mac）或 dir（Windows）
  • 创建一个GitHub账号——现在不用但先准备好
