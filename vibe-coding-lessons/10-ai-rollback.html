版本管理与回滚意识

让 AI 改代码之前一定要先存档！AI 可能一次改太多把整个项目改坏。学会小步修改、随时回滚。

📝 核心要点

  • 让AI改代码前：先 git commit
  • 一次只让AI改一个文件或一个功能
  • 改完立即测试，别等改完一堆再测
  • 出问题了：git checkout 回到改之前
  • 让AI把改动写成 patch 文件，人工审核后再应用
  • 小步修改 > 大步修改 > 一步到位（最危险）

✅ 打卡任务

  • 创建一个 Git 仓库，做第一次 commit
  • 让 AI 帮你写一个小功能，commit 前 diff 一下看改了什么
  • 练习 git checkout 回滚到上一个版本
