💾 阶段4 · 思维方式

随便改，改不坏的

你怕改代码。怕改坏了回不去。这很正常。解决办法简单到夸张：改之前存个档。就像你玩RPG打Boss前先存档——输了就重新来。Git就是你的存档系统。改之前 git commit，改坏了 git checkout。三秒恢复。从此你什么都不怕。
存档 → 修改 → 不满意 → 读档 — 三秒恢复

核心要点

  • git commit = 存档——三秒完成
  • git checkout = 读档——一秒回到存档点
  • GitHub = 把存档传到网上备份
  • 存档习惯=改代码的勇气。没存档=提心吊胆
  • 从今天开始：每次改代码前，先存档

动手试试

  • 在你电脑上找一个文件夹，运行 git init
  • 创建一个文件，写一行字，git add → git commit
  • 删掉那行字，保存，git checkout 把它恢复回来
