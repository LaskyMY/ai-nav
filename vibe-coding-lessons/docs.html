不要从头读文档

新手喜欢从头到尾读文档。最慢的学习方式。正确做法：你要做什么→搜"怎么做"→找到那一段→只看那一段→剩下的以后用到再看。你不需要把整本字典背下来才能写文章——需要哪个字就查哪个字。需要哪个功能就看哪个文档。
🖱 互动游戏

核心要点

  • 不要从头读文档——用到什么查什么
  • 搜"XX怎么做"比读完整API文档快十倍
  • 看文档的正确姿势：先找Examples→复制→改→跑通
  • 官方文档是最好的参考，但不是最好的教程
  • 让AI帮你总结："这个库怎么用，给我三个例子"

动手试试

  • 搜"Python怎么读文件"——只看你需要的函数
  • 打开一个工具的文档，找到Examples部分
  • 让AI用三个例子教你用一个新的库
