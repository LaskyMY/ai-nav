Claude Code 入门

概念扫盲完了。现在小K 想知道：那个传说中"能帮你写代码"的 Claude Code， 到底是什么？和网页版 Claude 有什么区别？我能不能用它来帮我学 UE？

📚 课程目录
SCENE · 下午茶歇

小K："G哥，你上次说 Vibe Coding 就是跟 AI 对话来写代码。 那具体用什么工具呢？网页版 Claude 能行吗？"

G 哥："网页版可以聊，但它碰不到你的项目文件。 你得把代码复制粘贴过去，它回答了你再粘贴回来——效率极低。 真正好用的方式是用 Claude Code。来，我帮你把它装好。"

为什么要懂 Claude Code

网页版 AI = 你在跟一个人打电话描述你的房间。Claude Code = 那个人直接站在你房间里。

Claude Code 能直接读你的项目代码——整个文件夹、Git 历史、 甚至你的 CLAUDE.md 项目说明文件。它不是"你告诉他你的代码长什么样"， 而是"它自己去看"。这带来的效率差距，不是 1.5 倍，是 10 倍。

Claude Code 到底是什么？

Claude Code 是 Anthropic 公司出的终端里的 AI 编程 Agent。 注意两个关键词："终端里"和"Agent"。

🌐 网页版 Claude 你在浏览器里打字问问题。
不能自己读文件、不能跑命令。
你复制代码给它 → 它回复文本 → 你粘贴回去。
适合：聊天、咨询、解释概念
⌨️ Claude Code（终端版） 你在终端里输入指令。
它能自己读你的项目、创建/修改文件、执行 Shell 命令、运行测试。
你说"帮我修这个 bug" → 它自己找原因 → 自己改代码 → 自己验证。
适合：实际的编码工作

一句话概括：网页版是"跟 AI 聊代码"，Claude Code 是"让 AI 帮你写代码"。

怎么装？

# 在终端里执行（任选一种）
npm install -g @anthropic-ai/claude-code     # npm 全局安装
# 或
brew install claude-code                      # macOS Homebrew
# 或
scoop install claude-code                     # Windows Scoop

装好之后，在你的项目文件夹里打开终端，输入：

claude

然后 Claude Code 就启动了——它会自动读取你当前文件夹里的所有代码，然后等你下指令。

💡 第一次使用的小建议

不要一上来就让它写复杂的功能。先试试这些简单的：
1. "帮我解释一下这个项目是干什么的"——看它能不能正确理解
2. "这个文件里的 xxx 函数做了什么？"——测试代码理解
3. "帮我把这个变量的命名改成更清晰的"——测试代码修改能力
做完这三步，你心里就有数它能干什么了。

CLAUDE.md —— 给 AI 的"项目说明书"

Claude Code 会优先读取你项目根目录下的 CLAUDE.md 文件。 这个文件就像你给新同事写的"项目入门指南"——只不过新同事是 AI。

# CLAUDE.md 示例
# 这是一个 UE 编辑器插件项目

## 项目概述
- 为 UE 5.5 开发编辑器工具
- 主要功能：批量处理静态网格体资产

## 编码规范
- 必须用大括号，即使 if 只有一行
- UObject 指针用 IsValid() 检查
- 所有新类加 KUROTOOLS_API 导出宏

## 关键文件
- MyPlugin.Build.cs：模块依赖配置
- MyToolCommands.cpp：编辑器命令入口

有了 CLAUDE.md，AI 就不需要每次都重新理解你的项目——它会记住你的编码习惯、 你的项目结构、你的特殊规则。这是 Claude Code 最强大的功能之一。

它还支持什么？快速过一遍

功能 一句话解释
MCP 还记得 §5 的"万能遥控器"吗？Claude Code 支持 MCP，能连接外部工具和数据库
子代理 把大任务拆成小任务，派给多个"分身"同时干活——比如一个分身查文档，另一个分身改代码
钩子(Hooks) 在特定时机自动触发自定义操作——比如"每次修改完代码后自动运行测试"
斜杠命令 快捷指令如 /review（代码审查）、/plan（制定计划）、/clear（清空对话）
Git 集成 自动写 commit message、生成 PR 描述、在 GitHub Actions 中运行
IDE 插件 可以装在 VS Code 或 JetBrains 里，不用切到终端
🔑 最重要的一条建议

先建 CLAUDE.md，再开始用 Claude Code。
这就像你带一个新同事入职——先给他看部门手册，再让他上手干活。 没有 CLAUDE.md 的 Claude Code，就像没有项目背景的新人，能做但做不快。 有了 CLAUDE.md，它干活的速度和准确度会明显提升。

Claude Code 不是替代你写代码的机器。
它是一个随时待命的编程搭档——
你看得懂的地方让它帮你写，你看不懂的地方让它帮你解释。
用得好，你的学习速度能快十倍。
