DAY · 05

理解UE项目文件

Unreal项目有几个关键文件你需要认识：.uproject是项目的身份证，告诉你这是什么项目、用哪个引擎版本。Content文件夹放所有资源。Config文件夹放设置。Source文件夹放C++代码。

核心要点

  • .uproject = 项目入口文件
  • Content/ = 模型、贴图、音效
  • Config/ = 项目设置
  • Source/ = C++源代码
  • Build.cs = 告诉编译器怎么编译这个模块

动手练习

  • 创建一个空 UE 项目，看看生成了哪些文件
  • 打开 .uproject 文件看看里面写的什么
  • 搜索"UE Module 是什么"深入了解
