搭建第一个桌面应用项目

纸上谈兵够了。这一节我们真的动手——用 Tauri + React 搭出第一个桌面窗口。 不用写任何复杂代码，你只需要知道每一步在干什么。

为什么要懂这个

看到成果是新人的最强动力。搭项目这一步，是你从"看书"到"动手"的分界线。

很多人学编程学了一两个月还在看教程、看文档，从来没自己跑起来过一行代码。 今天你就要打破这个循环——先跑起来一个东西，哪怕它只是一个空白窗口。

前置准备：你需要装什么

Node.js nodejs.org  → 下载 LTS 版本。它是 JavaScript 的"本地运行环境"——让你不打开浏览器也能跑 JS。
Rust rustup.rs  → Tauri 的底层用 Rust 写的，需要装 Rust 工具链。一路默认选项即可。
VS Code code.visualstudio.com  → 写代码的编辑器。免费的，装好即可。
WebView2 Windows 10/11 一般已自带。如果没有， 去微软官网下载 "WebView2 Runtime"。

创建项目

打开一个终端（PowerShell 或 CMD），输入以下命令：

# 1. 用 npm 创建 Tauri v2 项目（React + TypeScript 模板）
npm create tauri-app@latest floatthings -- --template react-ts

# 2. 进入项目文件夹
cd floatthings

# 3. 安装依赖（JavaScript 库）
npm install

# 4. 启动开发模式 —— 这会打开一个桌面窗口！
npm run tauri dev

几分钟后，你的桌面上会出现一个窗口。这个窗口里面是一个 React 页面—— 不是浏览器打开的，是一个真正的桌面应用窗口。恭喜，你已经是一个桌面应用开发者了。

这个命令背后发生了什么？

  1. npm create tauri-app 帮你下载了一个项目模板——里面已经有了基础的文件结构。
  2. npm install 下载了所有依赖库——React、Tauri 的前端 SDK、TypeScript 编译器等等。
  3. npm run tauri dev 做了两件事： 先启动前端开发服务器（React 的热更新页面）， 再启动 Tauri 的 Rust 后端，打开一个桌面窗口，把前端页面装进去。

项目结构一览

你的项目文件夹现在大概是这样的：

floatthings/
├── src/              ← 前端代码（React + TypeScript），你主要写这里
│   ├── App.tsx       ← 主界面
│   ├── main.tsx      ← 入口文件
│   └── ...
├── src-tauri/        ← Tauri 后端（Rust），负责系统调用
│   ├── src/
│   │   └── lib.rs    ← Rust 逻辑（窗口管理、系统托盘等）
│   ├── Cargo.toml    ← Rust 依赖配置
│   └── tauri.conf.json ← Tauri 配置文件
├── package.json      ← 前端依赖和脚本
└── tsconfig.json     ← TypeScript 配置

前端（src/）是你用 React + TypeScript 写界面的地方。 后端（src-tauri/）是你写 Rust 代码、跟操作系统交互的地方。 日常开发中 80%+ 的时间你都在 src/ 里写界面，只有需要调用系统功能时才碰 Rust。

💡 前端和后端怎么通信？

在前端（TypeScript）里，你调用 invoke('命令名', {参数})。 在后端（Rust）里，你用 #[tauri::command] 标注一个函数。 Tauri 自动帮你搭好桥——你在前端 invoke 一下，后端的 Rust 函数就会执行， 结果自动传回前端。这就是 Tauri 的核心工作机制。
